## 📂 Folder Structure
```bash
src
├── assets        # 이미지, 폰트 등 정적 파일
├── components    # 재사용 가능한 UI 컴포넌트
│   ├── common    # 버튼, 인풋 등 공통 컴포넌트
│   └── layout    # 헤더, 푸터 등 레이아웃
├── pages         # 페이지 단위 컴포넌트
├── hooks         # 커스텀 훅
├── services      # API 통신 로직
├── styles        # 전역 스타일
└── utils         # 유틸리티 함수
